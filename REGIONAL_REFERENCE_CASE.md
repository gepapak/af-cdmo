# Regional reference case and authorized reproduction

This optional post-confirmation case distinguishes an observed reference event, a local geometric comparison across different deliveries, and a controlled rewrite of one certificate. It does not change the original rank-five experiment or claim predictive accuracy under the added geometry.

Nordic CCM reported that the Nordic synchronous slack reference changed from Hovegaard/DK2 to SE2 on 28 May 2025 without changing market-coupling results. Its earlier Q&A describes separate Jutland and Nordic synchronous balances and assigns DK1-prefixed coordinates to Jutland. These establish a real reference issue and the meaning of the additional declared balance. [News update, 5 June 2025](https://nordic-rcc.net/wp-content/uploads/2025/06/News-update-5-June-2025.pdf), [Q&A EPR, answer dated 4 October 2023](https://nordic-rcc.net/flow-based/qa-epr/).

The frozen five-row equality system contains global balance and four zero-loss HVDC endpoint relations. It does not eliminate a shift constant only on the Nordic synchronous block. The optional audit declares a sixth homogeneous equality on every non-DK1-prefixed coordinate. This augmented geometry admits 36 within-Nordic differences among the nine physical Nordic zones and rejects all nine DK1-to-Nordic differences. Rejected queries have no reported prediction; relative synchronous-area price information would be required.

The archived DK2_SV_IMP row at 03:00 and 04:00 UTC on 28 May 2025 has unchanged RAM and a regional reference shift. Its projected direction and normalized RHS agree under the declared rank-six geometry. Its shadow price and auxiliary mark change, and the delivery times differ, so this is not an encoding-only pair of entire solved certificates. An exhaustive census includes every identity common to those two stored positive-dual certificates rather than selecting a row by its outcome.

The controlled adapter applies `a_new = a - a(SE2) * v_N` to every stored row of the 03:00 UTC certificate, where `v_N` is one on non-DK1 coordinates and zero otherwise; RAM, multipliers, and auxiliary marks remain fixed. This chooses a zonal SE2 representative; it does not reconstruct the actual nodal reference coefficient. The second certificate is generated for a contract test. It is not presented as an observed second publication. The original analytic 36 within-area differences already remain stable under this rule. The added geometry protects the complete quotient input, which matters for functions that use more than its linear analytic current.

All scripts below require explicit authorized local inputs. No provider data, fitted checkpoints, private results, or credentials are included in the public repository. The geometry JSON must supply `geometry.zone_order`; the CSV/gzip certificate uses the original named columns (`delivery_utc`, `mrId`, `cnecName`, `ptdf_l2_norm`, `unit_ptdf_*`, `ram`, `shadowPrice`, `flowFb`, `fmax`, `fref`, `fall`). Preserve the original coordinate names and units.

Freeze each protocol with `--plan` before its corresponding `--run`. Repeat the same arguments, replacing `--plan` with `--run`. Each run checks input and source hashes against its frozen protocol; amendments need a new output directory.

The optional learner audit requires an authorized original `af_qdm_residual`, `cqdm`, seed-7 checkpoint and its exact original training archive. It obtains target and RAM scales from checkpoint metadata and reconstructs the four historical auxiliary scales using the unchanged original timely/resolution expansion and fit cutoff. It loads the checkpoint unchanged, uses one CPU thread, accesses no price labels, and exports only the 36 admissible pair differences. The rank-six inputs are outside the checkpoint's training geometry: this tests stability under re-expression, not accuracy, calibration, or prospective benefit.

Exact reproduction of the reported learner result uses the original **confirmation** checkpoint with SHA-256 `1e75f9dd4f35fc2b5bde645dfb6f3b6f647ead4bb3688448a6760ba915e745c6` and training signature `b79a7c7ac071d91db8e4c73fed3e5b2454169db90b2bdbed584e5c37f7459bba`. Its fit ends before 1 January 2026 and validation ends before 1 March 2026. The May 2025 certificate lies within that fitting chronology; the controlled re-expression is an input-contract illustration, not a predictive holdout. The command verifies supplied method, kind, seed, source hashes and training-archive linkage; match this checkpoint digest to reproduce the particular reported 0.3769 result. No checkpoint is distributed.

The model-free scripts use NumPy and the standard library. The optional learner adds existing project dependencies PyTorch and pandas and reads the original archive to reconstruct its scales. Synthetic tests verify regional-gauge elimination, explicit query abstention, zero-normal rejection, and the distinction between geometric support equality and full marked-measure equality without accessing provider data.

In the completed bounded case, the rank-five quotient changes under the controlled rewrite whereas the rank-six marked atoms agree to floating-point tolerance. One unchanged original seed-7 AF learner produces a maximum 0.376903772354126 EUR/MWh difference across the 36 admissible pairs with rank-five preprocessing; the rank-six comparison produces zero difference at the tested float32 precision. This is one certificate and one frozen learner, with the new geometry outside its training setup. It supports the implemented re-expression contract and makes no estimate of market prevalence or forecasting benefit.
