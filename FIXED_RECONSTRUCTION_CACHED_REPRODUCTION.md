# Replaying the fixed reconstruction controls

The portable adapter reproduces the full already examined continuous-control
comparison from explicitly supplied, authorized numeric caches. It does not
acquire provider data, read prices, load models, train regressors, or run a neural
network. All timestamps, targets, and predictions remain private and are not
distributed with the public code.

The five controls are the analytic field and the fixed 12-, 33-, 48-, and
84-feature HGB residual regressors. The 33-feature control contains mass,
presence, and the complete 31-coordinate projected analytic current. The fit
uses the original 20,073 pre-November 2025 rows, ten separate squared-error HGB
regressors per control, and no December continuous calibration. These fits have
a different chronology from the original neural reconstruction experiment;
their comparison establishes no matched neural advantage.

Install the repository requirements and keep these three files together in
`scripts`: `audit_paper2_fixed_reconstruction_portable_cached_v1.py`,
`paper2_reconstruction_cached_metrics.py`, and
`paper2_nested_cached_metrics.py`. Run the meaningful arithmetic checks:

```powershell
python scripts/audit_paper2_fixed_reconstruction_portable_cached_v1.py --self-test
```

Supply the original executed reconstruction `protocol.json` and
`fixed_reconstruction_audit.json`, plus the confirmation and already consumed
later `*_targets_private.npz` and `*_predictions_private.npz` files generated by
the fixed study. These numeric caches use fixed-width string UTC timestamps and
load with `allow_pickle=False`. Target caches contain `target_field`,
`analytic_field`, and `residual_field`; prediction caches contain
`field_<method>` and `timestamp_mae_<method>` for all five controls. The original
ten-zone ordering is declared in the reference report. Cache generation is a
separate authorized-data procedure; caches are not bundled or manufactured by
this adapter.

```powershell
$replayArgs = @(
  '--confirmation-targets', 'AUTHORIZED/confirmation_targets_private.npz',
  '--confirmation-predictions', 'AUTHORIZED/confirmation_predictions_private.npz',
  '--later-targets', 'AUTHORIZED/later_consumed_targets_private.npz',
  '--later-predictions', 'AUTHORIZED/later_consumed_predictions_private.npz',
  '--reference-protocol', 'AUTHORIZED/protocol.json',
  '--reference-report', 'AUTHORIZED/fixed_reconstruction_audit.json',
  '--output', 'PRIVATE_REPLAY_OUTPUT'
)
python scripts/audit_paper2_fixed_reconstruction_portable_cached_v1.py @replayArgs --protocol-only
python scripts/audit_paper2_fixed_reconstruction_portable_cached_v1.py @replayArgs
```

The first command seals all inputs, source hashes, and the replay procedure. The
second checks timestamps, finite ten-zone fields, target/residual/analytic
identities, and every original per-timestamp loss. It recomputes the complete
five-method, ten-pair grid of pairwise MAE, pairwise RMSE, and the 90th percentile
of per-timestamp mean absolute pair error. Shared circular UTC-calendar-day
resamples preserve feed gaps and use 2,000 draws, seed 20261002, and 7-, 14-, and
28-day blocks. Integer-weighted quantiles equal an explicitly repeated sample.
Every point estimate and unadjusted interval must match the supplied original
report within `1e-8`; source bytes must remain unchanged.

This replay verifies numerical reproducibility. The periods and endpoints were
already examined, so it creates no fresh confirmation and no production or
welfare measurement. The original primary contrast is 84 minus current33 MAE
on the 14,482-row confirmation period, with seven-day uncertainty. It is
unresolved. On the already consumed 3,557-row later period, the current33 control
transfers better than the 84-feature control. Preserve all controls, windows,
metrics, and intervals when reporting these exploratory findings.
