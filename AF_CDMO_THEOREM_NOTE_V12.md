# AF-CDMO Quotient, Cotangent, and Stability Results

## Status and scope

This note states the local mathematical claims implemented by AF-CDMO v12. It
is a proof draft for independent review, not a claim of worldwide priority and
not evidence that the candidate Nordic affine geometry is operationally exact.
All results concern finite solved certificates with non-negative inequality
multipliers and a consistent affine equality system.

## 1. Setting

Let

```text
M = {x in R^d : E x = e}
```

be nonempty. Let `P` be the Euclidean orthogonal projector onto `ker(E)` and
let `x0 = E^+ e` be the minimum-norm point of `M`. Then every feasible point is
`x=x0+delta`, where `delta in ker(E)`.

A retained solved inequality row is `(a,b,lambda,q)`, with `lambda>0`,
`P a != 0`, and auxiliary fields `q` that are unchanged by a mathematical row
rewrite. Define

```text
r     = ||P a||_2,
u     = P a / r,
beta  = (b-a^T x0) / r,
m     = lambda r,
z     = (u,beta,q).
```

For a finite certificate `C`, define the positive measure

```text
Q_AF(C) = sum_i m_i delta_(z_i).
```

Zero-multiplier rows are omitted. Positive-multiplier rows with `P a=0` are
outside the implemented domain and fail closed because they are constant on
the feasible manifold and require separate semantics.

## 2. Registered equivalence

The certificate relation is generated by:

1. row permutation;
2. for `c>0` and any equality-row coefficient `eta`,

   ```text
   a'      = c a + E^T eta,
   b'      = c b + eta^T e,
   lambda' = lambda/c,
   q'      = q;
   ```

3. splitting or merging coincident canonical atoms while conserving
   non-negative mass; and
4. replacing `(E,e)` by `(T E,T e)` when `T` has full column rank.

The final operation may add redundant equality rows. Full column rank makes
`T` injective on the old equality residual, so it preserves the affine set.

## Theorem 1: equality-presentation invariance

If `T` has full column rank, `(E,e)` and `(T E,T e)` have the same affine
feasible set, minimum-norm base point, row space, tangent space, and orthogonal
tangent projector.

**Proof.** `T(E x-e)=0` if and only if `E x-e=0`, because `ker(T)={0}` on the
old equality-row coordinate space. Hence both systems define the same affine
set. Their homogeneous solution spaces are both `ker(E)`, so their Euclidean
orthogonal tangent projectors agree. A nonempty closed affine set has a unique
minimum-norm point, so the two base points also agree. QED.

## Theorem 2: row-level affine-gauge invariance

The canonical tuple `(u,beta,m,q)` is unchanged by every registered positive
scale/equality-gauge rewrite.

**Proof.** Since `P E^T=0`,

```text
P a' = c P a,
||P a'|| = c ||P a||.
```

Also `E x0=e`, so

```text
b'-(a')^T x0
  = c(b-a^T x0) + eta^T(e-E x0)
  = c(b-a^T x0).
```

Therefore `u'=u` and `beta'=beta`. Finally,

```text
m' = (lambda/c) ||c P a|| = lambda ||P a|| = m.
```

The auxiliary fields are unchanged by definition. QED.

## Theorem 3: completeness for one retained row

Two retained rows have the same canonical tuple and mass if and only if they
are related by exactly one positive scale, one equality-row-space addition,
and reciprocal multiplier scaling, up to non-unique coordinates for `eta` when
the equality system has redundant rows.

**Proof.** The reverse implication is Theorem 2. For the forward implication,
let `r=||Pa||`, `r'=||Pa'||`, and `c=r'/r>0`. Equality of directions gives
`P(a'-ca)=0`. The orthogonal complement of `ker(E)` is `im(E^T)`, so there is
an `eta` with `a'-ca=E^T eta`. Equality of normalized right-hand sides gives

```text
b'-(a')^T x0 = c(b-a^T x0).
```

Substituting the normal relation and `E x0=e` yields
`b'=c b+eta^T e`. Equality of masses gives
`lambda' r'=lambda r`, hence `lambda'=lambda/c`. QED.

## Theorem 4: finite-certificate maximal invariant

On finite retained positive-mass certificates, `Q_AF(C)=Q_AF(C')` if and only
if `C` and `C'` are equivalent under the registered row permutation,
scale/gauge, mass-conserving split/merge, and equality-presentation operations.

**Proof.** Invariance follows from Theorems 1-2 and additivity of a finite
measure. Conversely, merge coincident atoms in both certificates. Equal finite
positive measures then have the same distinct atoms and total mass at each
atom. A permutation matches those atoms, and Theorem 3 maps each matched row.
Reversing the mass splits recovers the original certificates. QED.

The theorem is exact only for the declared relation. It does not quotient
general dual degeneracy, arbitrary variable-coordinate transformations, or
non-coincident row substitutions.

## Theorem 5: restricted-Lagrangian conservation

For every feasible point `x=x0+delta`, `E delta=0`,

```text
sum_i lambda_i (a_i^T x-b_i)
  = integral (u^T delta-beta) dQ_AF(u,beta,q).
```

**Proof.** For each retained row,

```text
a^T(x0+delta)-b
  = (P a)^T delta-(b-a^T x0)
  = r(u^T delta-beta).
```

Multiplication by `lambda` gives `m(u^T delta-beta)`. Sum the finite terms.
QED.

In particular, the projected dual current is

```text
j(C) = integral u dQ_AF = sum_i lambda_i P a_i.
```

The implementation's analytic channel uses `-P j(C)` according to its chosen
price-gradient sign convention.

## Theorem 6: feasible-cotangent canonical representative

Two ambient covectors `p` and `p'` have the same value on every feasible
displacement if and only if `p-p' in im(E^T)`. Every such equivalence class has
a unique minimum-Euclidean-norm representative `P p in ker(E)`.

**Proof.** Equality on all `delta in ker(E)` is equivalent to `p-p'` being
orthogonal to `ker(E)`, which is `im(E^T)`. The orthogonal decomposition
`R^d=ker(E) direct-sum im(E^T)` makes `Pp` the unique tangent and minimum-norm
representative. QED.

This is why AF-CDMO projects its output. It is a Euclidean canonical choice,
not invariance to arbitrary changes of decision-variable coordinates.

## Corollary 6.1: invariant-task factorization

Every deterministic task that is constant on the registered certificate
equivalence classes factors uniquely through `Q_AF` on its image. This follows
from Theorem 4 by defining the downstream map on quotient representatives.

## Corollary 6.2: exact presentation-risk collapse

For an invariant target and loss, any predictor that consumes only `Q_AF` and
returns only the canonical feasible-cotangent representative has identical
prediction and loss over every registered presentation orbit. A finite
augmentation baseline cannot certify this statement outside its sampled
rewrites.

## Theorem 7: refinement-compatible attention

Within normalized attention heads whose value map depends on the canonical
atom but not its mass, continuity and exact invariance to every finite
mass-conserving split force the unnormalized attention weight to have the form

```text
w(z,m) = m kappa(z),  kappa(z)>=0.
```

**Proof.** Replacing mass `m1+m2` at one atom by masses `m1,m2` must preserve
the head for arbitrary values of all other atoms. Therefore the split atom's
combined unnormalized weight must equal its original weight:
`w(z,m1+m2)=w(z,m1)+w(z,m2)`. Continuity on the non-negative reals gives
linearity in mass. The converse is immediate. QED.

AF-CDMO's mass-weighted attention implements this sufficient form. The theorem
does not claim uniqueness over every possible neural architecture.

## Proposition 8: conditioning away from degeneracy

Fix `(E,e)` and hence `P,x0`. For two retained rows, write

```text
p=P a, p'=P a', r=||p||, r'=||p'||,
s=b-a^T x0, s'=b'-(a')^T x0.
```

Assume `r,r'>=epsilon>0` and `|s'|<=B`. Then

```text
||u-u'||
  <= 2 ||P(a-a')|| / epsilon,

|beta-beta'|
  <= (|b-b'|+||x0|| ||a-a'||)/epsilon
     + B ||P(a-a')||/epsilon^2,

|m-m'|
  <= r |lambda-lambda'| + |lambda'| ||P(a-a')||.
```

**Proof.** The normalization-map bound follows by adding and subtracting
`p'/r` and using `|r-r'|<=||p-p'||`. The beta bound follows from
`beta=s/r`, the same reverse-triangle inequality, and
`|s-s'|<=|b-b'|+||x0||||a-a'||`. The mass bound follows from adding and
subtracting `lambda' r`. QED.

The `epsilon^-1` and `epsilon^-2` factors expose the unavoidable conditioning
loss near a row that is constant on the feasible manifold. The implementation
therefore fails closed below a declared projected-norm tolerance instead of
silently emitting an unstable atom.

## 3. What the completed v12 experiment establishes

The frozen ten-seed synthetic benchmark verifies architectural sufficiency,
not the theorems' worldwide novelty or Nordic operational validity:

- six registered presentations are evaluated;
- maximum AF-CDMO ensemble drift is `1.662442002e-6` at tolerance `2e-5`;
- the analytic cotangent control has zero reported drift;
- non-quotiented controls exhibit material drift; and
- AF-CDMO has a modest clean matched-task gain over Slack-QDM and ambient CQDM.

The target is generated from AF quotient statistics, so the accuracy result is
a matched structural positive control. Real-market use remains blocked on an
operator-validated time-varying equality system and a derived map from the
feasible cotangent to the observed price field.
