# Reproducing the secondary Paper2 audits

These portable entry points reproduce the computations of the post-confirmation
feature-information, operational-triage and later-period audits. They accept
explicit local inputs and require no sibling project. The public distribution
contains source and synthetic tests. Provider records, input reports, timestamp
predictions, fitted models and neural checkpoints are excluded.

The original executed audit drivers remain unchanged in the private study
archive. Their completed reports identify their executed source hashes. The
portable adapters have different hashes because argument handling and input
relocation changed; numerical computation is preserved. Their own reports record
the adapter and input hashes. Reproduction still requires authorized artifacts
that match the expected frozen hashes; freshly downloaded data may differ.

| Entry point | Required private inputs | Fits a model? |
|---|---|---|
| `audit_paper2_operational_triage_portable_v1.py` | Original confirmation report, temporal audit, per-time confirmation predictions, frozen manifest, certificate/price source files and geometry | No |
| `audit_paper2_learning_value_portable_v1.py` | Same original confirmation report/predictions/manifest; historical certificate/price sources, geometry, development artifact and AF-CDMO confirmation reference | Fixed historical HGB controls only; no neural fit |
| `audit_paper2_later_temporal_portable_v1.py` | Original confirmation report, consumed later QCT report and NPZ predictions, original frozen neural checkpoints; optional identically copied checkpoints and original-HGB probability CSV/NPZ | No |
| `audit_paper2_later_hgb_portable_v1.py` | Original/later reports and NPZ predictions; authorized later certificate/price sources; original geometry and qct_full seed7 scaling checkpoint; trusted historical HGB plus Platt model | No |

Run from the repository root. The following PowerShell examples use local
placeholder filenames. No inputs are acquired by these auditors. A trusted
historical HGB is generated by the feature-information reproduction; the later
HGB auditor does not refit or recalibrate it. Serialized model files must come
from a trusted local reproduction because their loader executes Python objects.

## Operational triage

```powershell
python scripts/audit_paper2_operational_triage_portable_v1.py --self-test
python scripts/audit_paper2_operational_triage_portable_v1.py --report private/confirmation.json --temporal-audit private/temporal_audit.json --predictions private/confirmation_predictions.csv.gz --manifest private/frozen_manifest.json --input-root private/authorized_paper2 --output results/operational_triage_portable_v1
```

`--input-root` relocates source paths anchored below the original `Paper2`
directory without changing the report bytes or expected hashes. Explicit
`--dual-archive`, `--price-root` and `--geometry-audit` overrides support a
different local layout. The calculation reproduces the original confirmation
cohort and fails if its labels, timing, scores or registered counts differ.
Daily budgets use `ceil(budget * available intervals each UTC day)` and stable
chronological ties. Seven-day bootstrap draws include missing calendar days.
The price-feed-withholding workflow is hypothetical: this is not an observed
outage or a deployment-benefit study.

## Historical feature-information audit

```powershell
python scripts/audit_paper2_learning_value_portable_v1.py --self-test
python scripts/audit_paper2_learning_value_portable_v1.py --report private/confirmation.json --predictions private/confirmation_predictions.csv.gz --manifest private/frozen_manifest.json --input-root private/authorized_paper2 --output results/learning_value_portable_v1 --protocol-only
python scripts/audit_paper2_learning_value_portable_v1.py --report private/confirmation.json --predictions private/confirmation_predictions.csv.gz --manifest private/frozen_manifest.json --input-root private/authorized_paper2 --output results/learning_value_portable_v1
```

The adapter freezes its source inventory and fixed analysis before scoring.
Its output must be below the local repository's `results` directory. Input
overrides also include `--development-artifact` and `--confirmation-reference`.
The inherited HGB configuration uses seed 20261002, fitting before November
2025 and Platt calibration only in December 2025. It preserves the exact
float32-derived confirmation event threshold, verifies the original full-HGB
probabilities within `1e-9`, and compares 12 analytic-field features with all 84
fixed quotient features. This is a post-confirmation diagnostic, not a new
blinded model-selection study. Numerical threads are limited to one. If
`psutil` is installed, a 600 MiB available-memory guard also runs; this optional
guard is not required by the public dependency set.

## Consumed later-period temporal audit

```powershell
python scripts/audit_paper2_later_temporal_portable_v1.py --original-report private/confirmation.json --later-report private/consumed_later_qct.json --predictions private/consumed_later_qct.predictions.npz --checkpoint-root private/original_checkpoints --hgb-predictions private/later_original_hgb_predictions.npz --output results/later_temporal_portable_v1 --plan
python scripts/audit_paper2_later_temporal_portable_v1.py --original-report private/confirmation.json --later-report private/consumed_later_qct.json --predictions private/consumed_later_qct.predictions.npz --checkpoint-root private/original_checkpoints --hgb-predictions private/later_original_hgb_predictions.npz --output results/later_temporal_portable_v1 --run
```

Omit `--hgb-predictions` in both commands if original-HGB individual scores
are unavailable. Then neural paired intervals are available, but the older
reconstructed-HGB contrast is point-only and retains its documented historical
threshold discrepancy. An optional `--comparison-checkpoint-root` verifies
checkpoint copies against original hashes. A supplied HGB CSV or NPZ must have
exactly aligned timestamps, labels and residual magnitudes; score alignment
alone does not prove original model identity. Establish that identity through
the historical reproduction audit.

The expected NPZ contains `timestamp_utc`, `target`,
`residual_magnitude_eur_mwh` and `probability__qct_full`,
`probability__qct_no_tangent`, `probability__uniform_set_transformer` arrays.
The later report supplies the consumed cohort and checkpoint provenance using
the locked QCT chronology report schema. Its filename and directory are
arbitrary. It must describe the already examined 20 August–30 September 2026
cohort. This reuse is a post-confirmation secondary analysis, not untouched
external confirmation.

The standalone `paper2_secondary_temporal_metrics.py` preserves the original
later-analysis mathematics and RNG order. Its circular blocks use observed UTC
days and retain complete sampled blocks; this differs from the complete-calendar
grid used in the main triage audit. Later common budgets rank the entire cached
cohort with `floor(budget * intervals)`, so they represent retrospective global
workload matching. They are not prospective daily policies. Both 7-, 14- and
28-day intervals and negative transfer results are retained.

## Reconstructing later original-HGB scores

```powershell
python scripts/audit_paper2_later_hgb_portable_v1.py --original-report private/confirmation.json --later-report private/consumed_later_qct.json --predictions private/consumed_later_qct.predictions.npz --model results/learning_value_portable_v1/full_quotient_hgb_reproduction.joblib --dual-archive private/later_duals.csv.gz --price-root private/later_prices --geometry-audit private/geometry.json --checkpoint private/original_checkpoints/qct_full__seed7.pt --output results/later_hgb_portable_v1 --prepare
python scripts/audit_paper2_later_hgb_portable_v1.py --original-report private/confirmation.json --later-report private/consumed_later_qct.json --predictions private/consumed_later_qct.predictions.npz --model results/learning_value_portable_v1/full_quotient_hgb_reproduction.joblib --dual-archive private/later_duals.csv.gz --price-root private/later_prices --geometry-audit private/geometry.json --checkpoint private/original_checkpoints/qct_full__seed7.pt --output results/later_hgb_portable_v1 --score
```

Feature preparation verifies source and scaling hashes and exact cached cohort
alignment. Scoring verifies the original Platt map, uses the original December
cutoff, and computes paired contrasts against each neural method. All later
sources are used only for feature extraction and evaluation. No later fitting,
calibration, threshold selection or neural inference occurs. The generated
`later_original_hgb_predictions_private.npz` can supply `--hgb-predictions`
to the temporal adapter.

Run the synthetic portability contracts with
`python -m pytest tests/test_paper2_portable_auditors.py -q`. Those tests need
neither provider artifacts nor a sibling project. They check CLI availability,
source relocation without weakened hashes, exact threshold precision, aligned
prediction inputs, stable workload decisions and paired statistical calculations.

## Additional exploratory controls and integrity endpoints

The initial 12-versus-84 feature diagnostic above is supplemented by the complete
analytic-current control. Retain these later additions and their negative
results when reproducing or interpreting the paper:

- [NESTED_LEARNING_VALUE_CACHED_REPRODUCTION.md](NESTED_LEARNING_VALUE_CACHED_REPRODUCTION.md)
  covers all four fixed-HGB risk controls: 12 physical-field/mass summaries,
  33 complete-current/mass coordinates, 48 first-moment features, and all 84
  features. It can replay trusted saved models or reproduce fixed historical
  fits from authorized caches, with December Platt calibration. Complete
  current33 improves confirmation Brier loss from 0.081044 to 0.052496 relative
  to field12; 84 features attain 0.045200, but their Brier difference from
  current33 has a seven-day interval crossing zero. On the already examined
  later period, current33 has Brier 0.027561 versus 0.034390 for 84 features;
  this adverse point contrast also has an unresolved seven-day Brier interval.
  These exploratory estimator comparisons establish neither neural necessity
  nor Bayes sufficiency, and comparisons remain unadjusted for multiplicity.
- [FIXED_RECONSTRUCTION_CACHED_REPRODUCTION.md](FIXED_RECONSTRUCTION_CACHED_REPRODUCTION.md)
  replays the analytic baseline and fixed 12/33/48/84-feature continuous
  reconstruction controls from authorized target/prediction caches, without
  fitting or neural inference. Current33 and 84 confirmation MAEs are 1.72385
  and 1.72375 EUR/MWh; their primary difference is unresolved. Later current33
  MAE is 0.96644 versus 1.59909 for 84 features, with 84-minus-current33
  difference 0.63265 and seven-day interval [0.10727, 1.36607]. The later
  cohort was already examined, and these controls use a fitting chronology
  different from the original neural study. The complete grid, including
  adverse results and secondary metrics, must remain visible.
- [CONTINUOUS_REFIT_REPRODUCTION.md](CONTINUOUS_REFIT_REPRODUCTION.md)
  complements that cache replay with genuine fixed historical HGB and
  standardized Ridge refits from authorized feature/target caches. It uses
  the same complete-current controls and evaluates all methods and contrasts,
  including adverse outcomes. Standardization is fitted on historical fit
  rows only; later data are used for evaluation. This is exploratory
  estimator comparison, not new blinded confirmation or a neural-necessity
  claim.
- [ATTRIBUTION_PATHS_REPRODUCTION.md](ATTRIBUTION_PATHS_REPRODUCTION.md)
  replays the original PTDF-times-shadow-price and unit-direction-times-mass
  ingestion paths, with all recorded provenance tags and confirmation
  opportunities. It exposes 280 near-zero primary routing flips and 3,633
  exact-zero-screen changes; no observed routing flip meets the measured
  two-path margin certificate. This checks numerical integrity within one
  archive, not independent acquisition, causal TSO attribution, an observed
  equivalent publication revision, or prospective benefit.
- [REGIONAL_REFERENCE_CASE.md](REGIONAL_REFERENCE_CASE.md) reproduces an
  observed reference mechanism, an adjacent-hour geometric census, and a
  separate controlled regional adapter. The event's shift lies outside the
  frozen rank-five geometry. The optional rank-six geometry preserves the
  controlled marked measure, emits 36 admissible within-area queries and
  abstains on nine cross-area queries. Its one unchanged learner comparison
  uses a historical certificate within its fitting chronology and inputs
  outside the original training geometry; it tests re-expression stability,
  not accuracy. The source-inspired zonal SE2 representative does not
  reconstruct the actual nodal reference coefficient, and the observed
  adjacent-hour rows do not establish equivalent whole solved certificates.

Each linked procedure requires its explicit authorized inputs and records
source/input provenance. Caches, models, source records, and executed private
reports remain excluded from the code-only package. No analysis supplies a
natural same-delivery rewrite frequency or a prospective analyst-benefit
measurement.
